腾讯翻译使用 SecretId + SecretKey 双密钥：SecretId 填在上方「SecretId」字段。 在 腾讯云控制台 → API 密钥管理 申请密钥， 并在 机器翻译控制台 开通服务；基础翻译每月有免费额度，超出后按字符计费。

微软翻译使用 Edge 内置的网页翻译端点，无需密钥与接口地址，直接点「测试连接」即可验证。 该端点为未公开的在线服务（非 Microsoft 商业 SLA），文本会发送到微软服务器；如端点不稳定请改用其他服务商。

谷歌翻译使用 Google 翻译服务端点，无需密钥与接口地址，直接点「测试连接」即可验证。 该端点为未公开的在线服务（非 Google 商业 SLA），文本会发送到 Google 服务器； Google 服务在国内通常无法直连，测试失败多半是网络不可达，请改用其他服务商。

Ollama 默认运行在本机 http://localhost:11434，接口地址填 http://localhost:11434/v1（只填主机地址时扩展会自动补 /v1）。 本地 API 无需密钥；请先用 ollama pull 模型名 下载模型，再点「获取模型」或手动填写模型名称。 若连接返回 403，请将当前扩展的 chrome-extension://<扩展 ID> 加入 Ollama 的 OLLAMA_ORIGINS 后重启 Ollama 服务。

还没有个人规则。大多数站点开箱即翻；只在遇到问题时才需要规则。
规则仓库（订阅）
