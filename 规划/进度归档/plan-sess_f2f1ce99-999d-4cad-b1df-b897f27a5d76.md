# UI 全面重构：从「古风」到「macOS」—— 工具回归工具

## 一、第一性原理诊断：为什么现在的 UI 难看

1. **场景错位**（根本问题）：浏览器扩展的 UI 本质是**工具面板**——它悬浮在现代网页之上，视觉语言必须与操作系统协调，而非自成一体的文化表达。衬线字体、加宽字距、宣纸暖色在 340px 弹窗里显得陈旧且拥挤。
2. **控件原始**：裸 checkbox、原生滑杆、没有成体系的 hover/focus/active 状态反馈——macOS 质感的一半来自控件的精致状态。
3. **信息架构平铺**：设置页三张卡片一滚到底，没有导航分区；沉浸式翻译的设置页用「左侧分区导航 + 右侧设置行」让查找变成点按而非滚动。
4. **缺乏材质层次**：macOS 美学的核心是分层（背景面 / 卡片面 / 控件面）+ 柔和多层阴影 + 连续圆角；现状是硬边框扁平面。

## 二、设计语言：macOS 美学的工程化转译

```css
/* 设计令牌 */
--bg: #f5f5f7            /* 苹果经典浅灰底 */
--card: #ffffff           /* 浮起的白色卡片 */
--text: #1d1d1f;  --text-2: #6e6e73;  --text-3: #86868b;
--separator: rgba(0,0,0,.08)
--accent: #007aff         /* 系统蓝，唯一强调色 */
--toggle-on: #34c759      /* 开关绿 */
--shadow-card: 0 1px 3px rgba(0,0,0,.06), 0 4px 12px rgba(0,0,0,.04)
radius: 卡片 12px / 控件 8px / 主按钮 10px
font: -apple-system, BlinkMacSystemFont, 'SF Pro Text', 'PingFang SC', 'Segoe UI', Roboto, sans-serif
motion: .18s cubic-bezier(.25,.1,.25,1)；hover 背景/描边微变，active scale(.98)
```

- **暗色模式**：`prefers-color-scheme: dark` 一套变量整体翻转（`#1c1c1e` 底 / `#2c2c2e` 卡片），低成本高质感
- **交互动作规范**：所有可点元素有 hover 态；主按钮按下轻微下沉；focus 显示系统蓝光环 `box-shadow: 0 0 0 3px rgba(0,122,255,.25)`

## 三、文件改动（纯表现层，业务逻辑与存储协议零改动）

### 1. `popup/index.html` — 动作面板重绘
- 头部：48→28px 圆角方形 App 图标（系统蓝底、白色"译"、SF 字重）+「墨译」+ 版本小字，去印章衬线
- 主 CTA：「翻译整个页面」系统蓝填充按钮 + 右侧灰色 `⌥⇧T` kbd 胶囊角标
- 次级行：「还原页面」灰色描边按钮 + 语言 select（macOS 化外观）
- 状态区：前缀状态图标（进行中=旋转圈 / 成功=✓ 绿 / 失败=⚠ 红），文案沿用现有三态类名 `status/busy/ok/error`
- 底部：「高级设置」淡灰链接行
- **所有元素 id 不变** → `popup/main.ts` 零改动

### 2. `options/index.html` — 参考 System Settings + 沉浸式翻译的分区布局
```
┌─────────┬──────────────────────────────┐
│ 图标墨译 │  [翻译服务]                    │
│         │  ┌──────────────────────────┐ │
│ ▍通用    │  │ API Endpoint      [____] │ │
│ ▍翻译服务│  │ 行：label+描述 | 控件      │ │
│ ▍译文样式│  └──────────────────────────┘ │
│ ▍快捷键  │  [译文样式] …                  │
└─────────┴──────────────────────────────┘
```
- 左侧 sticky 侧边栏：App 标识 + 四个导航项（通用/翻译服务/译文样式/快捷键），active 态浅蓝底蓝字
- 右侧内容：每分区一张白卡片；设置行 = 左侧「标签 + 描述小字」右侧「控件」，行间 hairline 分隔
- **Toggle 开关**替代 checkbox（推理开关，纯 CSS 实现，id 不变）
- 六个标记预设 → **可视化卡片网格**（大 swatch 示意块 + 名称，选中态系统蓝描边）
- 颜色行（mac 取色方块）、字号行（styled range + 百分比）、实时预览卡保留
- 「保存配置」「测试连接」「保存样式」按钮 mac 化；回读校验等全部逻辑不动
- 「通用」新分区（轻内容）：显示版本、恢复默认样式按钮——让导航四项都有实感

### 3. `options/main.ts` — 仅新增导航行为
- 点击侧边栏项 → 平滑滚动到对应分区 + active 切换；IntersectionObserver 反向高亮
- 其余（防抖保存/回读校验/脏状态/预览/连接测试）**一行不改**

### 4. 明确不动
`config.ts`、`background.ts`、`content/*`、`translationRenderer.ts`、全部测试文件——52 项现有测试保证功能零回归；页面内译文样式属于产品功能而非浏览器 UI，不在本次范围。
