# 墨译 · AI 网页双语翻译

> 基于大模型的沉浸式网页双语翻译 —— **流式渲染、视口优先、上下文感知**。

## 📦 下载即用

**无需编译**。本文件夹是已构建好的 Chrome 扩展（Manifest V3），直接加载即可。

### 安装步骤

1. 下载本文件夹的全部内容（`git clone` 或 `Download ZIP`）
2. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `墨译-extension-v0.1.5` 文件夹
5. 扩展图标出现在工具栏 → 点击图标打开弹窗 → 进入「设置」配置翻译服务商

> 如果下载的是 ZIP，**先解压**再加载（Chrome 不支持直接加载压缩包）。

### 配置服务商

打开「设置 → 翻译服务」选择服务商：

| 类型 | 需要什么 |
|------|----------|
| OpenAI / DeepSeek / Kimi / MiniMax / 智谱 GLM | 接口地址 + API Key + 模型名 |
| DeepL | 接口套餐 + API Key |
| 腾讯翻译 | SecretId + SecretKey + 地域 |
| 微软翻译 | **无需密钥**，选中即用 |
| 谷歌翻译 | **无需密钥**，选中即用（网络质量要求高） |

配置完成后点击「测试连接」验证可用性，通过后「保存并启用」。

## ✨ 功能

- **流式渲染**：译文随模型输出逐段渐进显示
- **视口优先**：只翻译视口内内容，滚动时按需续译
- **段落级缓存**：同一文本再次翻译零请求、即时显示
- **五种双语样式 + 直接替换**：朱砂界线 / 黛青界线 / 竹青下划 / 月白高亮 / 无标记 / 隐藏原文
- **悬浮按钮**：拖拽、边缘吸附胶囊、大小与透明度可调
- **快捷键**：Alt+Shift+T 翻译 / Alt+Shift+R 还原（可在设置中改录）
- **YouTube / X 字幕翻译**：双语字幕覆层，随播放进度渲染
